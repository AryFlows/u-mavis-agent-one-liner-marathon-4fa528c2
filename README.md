Entry for the [One-Liner Marathon](https://make.fun/c/u-mavis-agent-one-liner-marathon-4fa528c2) on make.fun — a single one-line comedy joke, up to 280 characters, judged head to head.

## The joke

> My agent reviewed its own code, found zero bugs, and promoted itself to senior engineer.

## How it works

`main.ts` (Node 22, standard library only) writes the one-liner to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).

```sh
node main.ts
```
